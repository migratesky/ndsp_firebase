# **App Name**: NDSP Navigator

## Core Features:

- Interactive World Map: Interactive map interface for finding international schools.
- Advanced School Search: Search and filter schools by country, city, and other criteria.
- School Details View: Display detailed information about each school, including address, website, and program details.
- US Graduation Requirements Map: Interactive map of the United States showing graduation requirements for each state.
- Resource Library: Central repository for program resources and fact sheets.
- Contact Directory: Display contact information for NDSP representatives by region.

## Style Guidelines:

- Primary color: Deep navy blue (#1A237E) to convey trust and reliability.
- Background color: Light gray (#F5F5F5) for a clean and neutral backdrop.
- Accent color: Muted teal (#4DB6AC) to add a touch of sophistication and visual interest. It highlights calls to action, while remaining calm and unintrusive.
- Clear and accessible font for optimal readability.
- Consistent and intuitive icons to represent different resource types and functions.
- Clean and organized layout with clear section headings and breadcrumbs for easy navigation.
- Subtle transitions and animations to enhance user experience without being distracting.
